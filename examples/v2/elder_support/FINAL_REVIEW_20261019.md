## 问题 1：数据科学性，比普通随机更优在哪 —— 第 2 类

**已做**
- 画像输入分布逐维锚定：性别、年龄段、自评健康、孤独感五档、子女数、
  子女常探望比例（CLHLS 2021 独居子样本），子女距离（CHARLS 2015）。
- 同 seed 四条件共用同一份 `profiles_s$seed.json`（`run_batch.sh`），
  构成同一批老人的配对反事实——这是相对普通随机最硬的优势，论文未讲透。
- `analyze.py` 有末期截面打靶。

**不足**
- 从未与“普通随机画像”做过对照，“更优”只是断言。
- 每 seed 仅 20 人，抽样噪声大；未检查每个 seed 的 20 人是否贴合目标分布。
- 各维度独立抽样，丢失真实数据中年龄、健康、子女数、孤独感的相关结构。
- 外向性、邻里关系数与强度未校准；LLM 层接触过程未校准（论文已承认）。

**下一步**
- [ ] 规则层消融（零成本）：校准画像 vs 均匀随机画像各 20 seed，比较输出侧
      靶标命中（基线孤独约 15%、三年发生率 27.2%、持续率 53.3%）。
- [ ] `gen_profiles.py` 改为按权重直接重抽 CLHLS 独居受访者记录，保留联合分布。
- [ ] 补画像保真表：逐 seed 与合并后各维度相对靶标的偏差。
- [ ] 答辩口径：输入锚定调查、输出可对照靶标检验、种子用于配对反事实；
      不说“数据是真的”。

## 问题 3：社会工作还是社会学 —— 第 5 类（口径选择）

| 方案 | 判断 |
|---|---|
| 1. 保留社会工作，修改口径 | 推荐，作为基础 |
| 2. 保留社会工作，增加内容 | 只做轻量版本，与 1 组合 |
| 3. 改成社会学 | 不推荐 |

- 不改社会学：社会学评委会追问理论贡献与真实数据，正是最弱处；干预本身
  是社工服务，去掉社工语境后“为什么比这三种”更难回答；改动大、收益不定。
- “因人而异、细致入微”是质性个案研究的长处，仿真做不到，硬补显得勉强。
- 推荐定位：“面向老年社会工作问题的智能体仿真研究”，与赛道一致。

**下一步**

      撤出后反应），附 run / seed / agent / month 与日志位置，标注为模拟案例。
- [ ] 问题 2 的对照表。
- [ ] 待老师确认：是否给焦点老人实现完整个案流程（评估、计划、跟进、结案）；

### 目的 A：时机有参考价值，宏观不弱于 / 接近人的判断

**现状**：时机只在规则层扫描；“延迟成本按月线性累积”在 `tab:prescribed`
中已标为规定（干预即时起效的直接推论）；LLM 层时机对照未做；与人类判断
完全未比。

**表述问题**：结论由规则决定时，与人比得再像也不证明仿真有价值；现实中
无“最佳时机”真值，只能论证“与专业判断一致”，不能论证“优于人”。

**下一步**
- [ ] 让时机效应可涌现：加入启动滞后与覆盖爬坡；LLM 层做预防期 / 预警期 /
      危机期三个启动时点对照（花钱）。
- [ ] 人类基准（不做一线社工问卷）：以成文的人类决策规则作为“人的判断”，
      例如民政部门特殊困难老年人探访关爱的风险分级与探访频次规定、社工机构
      的个案优先级与开案标准；把这些规则编码成干预策略，在同一模型下与仿真
      推荐策略比较“先介入谁、何时介入”的一致率与结局差异，并与简单规则基线
      （如只按年龄排序）比较。可请 2–3 位交流的老师对少量情景做定性核对，
      不作统计结论。目标表述：“仿真推荐策略在宏观结局上不弱于成文实务规则，
      且优先级判断与之大体一致”。
- [ ] 输出侧对照真实数据（问题 1、问题 6 的靶标检验）作支撑。

### 目的 B：harness 自我迭代、自动改进

**现状**：已做有限版本。LLM 在预注册小空间（3 干预 × 启动月 × 时长）提案，
规则层评估，5 轮复现网格最优区间，无新发现；该空间网格即可遍历，LLM 搜索
未增加价值。

**表述问题**：“迭代出最好的数据”会被理解为挑选有利结果，必须换掉。

**下一步**
- [ ] 重定义为自动校准：harness 提议修改模型参数（衰减率、深谈概率、
      `post_persist`、焦点老人提示词等），目标是缩小与校准靶标的差距；靶标分训练集
      与留出集，用留出集检验，防止过拟合。
- [ ] 在校准后的模型上做策略搜索：扩大到网格无法遍历的空间（按个人风险分诊、
      逐步减量的退出方案），结果再交给目的 A 与社工判断比较。

主线：调查锚定的模型 → harness 自动校准、留出靶标验证 → harness 搜索介入策略
→ 与成文实务规则比较一致性与结局。
