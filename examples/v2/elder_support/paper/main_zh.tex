\section{引言}
中国 65 岁以上独居老人的孤独与社会隔离问题规模庞大：CLHLS 2008/09 波数据显示独居老人``感到孤独''比例达 52\%，几乎两倍于非独居老人（29.5\%）\citep{wei2022living}（背景引用；本文校准使用 2021 波独居子样本与``经常/总是''口径，不可直接比较）。社区回应这一问题有三条主要渠道，分属三个政策领域：\textbf{社工探访}（社会工作：专业社工按风险分级上门）、\textbf{互助结对}（社会保障：低龄健康老人与高龄老人结对、以时间银行积分维系的互助养老）、\textbf{志愿匹配}（社会管理：基层治理中经数字平台按需派出志愿者）。三者在实务中常组合使用，但有三个问题在实证文献中始终难以回答：

\textbf{（一）服务撤出之后，关系能否留下？}评估几乎都在项目期内或结束时测量结局\citep{lu2024timebank}；撤出后的反事实轨迹无法观测——同一批老人不能既接受又不接受干预。

\textbf{（二）何时介入代价最小？}轮候与预算约束使启动时机成为真实的政策变量，但时机的边际代价从未被系统量化。

\textbf{（三）这样的模拟可信吗？}生成式智能体\citep{park2023generative}能在可控环境中产生带理由的行为决策，并在同一随机种子下重放``平行世界''，正适合回答前两问；但它面临三重质疑：数据是否凭空捏造、结论是否可复现、``发现''是否只是环境规则的回声。

本文以独居老人社会支持为案例，围绕第三问建立方法，再用它推演前两问。贡献有三：

\begin{enumerate}
  \item \textbf{可迁移的科学性纪律}：预注册假设与效度门槛、失效 run 归档与根因分类、含沉没成本的成本核算，以及\textbf{结果来源对照表}——逐条标明哪些结果是规则与参数的直接推论（表~\ref{tab:prescribed}）。
  \item \textbf{数据锚定与留出验证}：画像按调查分布生成，并以预注册消融证明它比普通随机更贴近现实；孤独动力学由提案--评估回路在训练靶标上校准、以留出靶标验收（第~\ref{sec:calib}~节）。
  \item \textbf{分层政策沙盒}：LLM 焦点层嵌入零 API 成本的规则层，干预机制、强度、时机与撤出后延续均为外置参数，支持大样本情景扫描与置零检验；分层拆解量化两层对宏观结果的贡献（表~\ref{tab:layers}）。
\end{enumerate}
案例结果均为显式参数下的情景推演，用于演示方法与生成可检验的实务假设。核心结论与创新归纳于第~\ref{sec:core}~节；评审关切与对应章节见附录表~\ref{tab:review}。

\section{相关工作与理论基础}
\textbf{社会支持理论与护航模型。}护航模型（convoy model）\citep{kahn1980convoys}把老年人的社会关系视为随生命历程移动的分层护航队：内层（配偶、子女）稳定但受丧偶、健康冲击侵蚀，外层（邻里、朋友）流动性高。本模拟的关系账本直接操作化这一结构：每条关系有强度、类型与最近联系时间，无联系则衰减。

\textbf{关系衰减的实证形态。}Burt 的跨研究拟合表明关系衰减率非常数、呈幂函数，``越老的关系越稳''\citep{burt2000decay}；老年人关系终止亦有直接测量\citep{kleinikkink1999broken}。我们在第~\ref{sec:honest}~节以 Burt 口径实测本模型的存活曲线并如实报告结构性偏差。

\textbf{孤独干预的效应证据。}Masi 等的荟萃给出四类干预的效应标尺（社会认知类 $d=-0.598$ 最大）\citep{masi2011meta}；Hoang 等按亚型拆分显示技术类干预 CI 跨零、多组件干预在社区场景显著\citep{hoang2022interventions}。个案管理的两个 RCT（独居老人\citep{ristolainen2020effects}、社区失能老人\citep{taube2018case}）方向一致但 ITT 均保守。时间银行的准实验证据表明效应至少维持到项目终点且无挤出\citep{lu2024timebank}。这些文献为三种干预提供效应方向与相对强弱的参照；本文的干预参数数值尚未与这些效应量对齐（第~\ref{sec:interventions}~节）。

\textbf{生成式智能体模拟。}Park 等确立了 LLM 智能体产生可信社会行为的范式\citep{park2023generative}。本文的差异在于：以政策比较为目的的预注册实验设计、真实调查数据校准、以及对模拟有效性的系统核查。

\section{方法：分层混合模拟}
\subsection{总体架构}
模拟基于 AgentSociety2 框架（Ray 并行、全程 trace 留痕、决策可回放）。20 名独居老人构成支持网络；其中 6 名为\textbf{LLM 焦点老人}（PersonAgent，模型 gpt-5.6-sol），每月经多轮工具循环感知环境、检索记忆、做出行动决策并输出自然语言理由；其余 14 名与全部网络动力学由\textbf{规则层}驱动（关系衰减、月度事件、干预机制），不消耗 LLM 调用。焦点层提供机制与叙事证据，规则层保证网络结构的完整性并支撑零成本的大样本敏感性扫描。实测调用密度约 13.8 次/焦点老人$\cdot$月。\textbf{两层的接触生成机制不同}：规则层老人每月按子女联系频率与外向性自动产生联系；焦点老人的联系只来自其自身工具行动（打电话、走访、求助、参加活动）与干预者的来访，LLM 一个月不行动即记为当月无接触。这一差异是第~\ref{sec:layers}~节两层孤立率水平相差三倍的直接原因，也意味着焦点层孤立率同时度量``老人是否孤立''与``LLM 是否行动''。整体结构见图~\ref{fig:arch}。

\subsection{环境路由}\label{sec:router}
焦点老人不能直接调用环境工具，只能通过 \texttt{ask\_env} 用一句自然语言向环境提出请求，并声明本次是只读（观察）还是可写（行动）。代码生成路由把这句话与该模式下可用的工具签名交给另一个模型，生成并在沙箱中执行调用代码，再把结果以自然语言返回给老人。环境注册的工具分两类：只读工具（观察自身状况、社区报告）与写工具（打电话、串门、求助、参加活动）；只读请求只能调用前者。这一层是模型与环境之间唯一的接口，它对能力边界的表述会直接影响 agent 是否行动。2026-10-20 前，只读回答没有区分``这一次不能写''与``没有这个功能''；修复后，询问功能是否存在时由注册表直接作答（``工具存在，本次只读不能调用，要行动请用 readonly=false''），生成结果若仍否认已注册工具则被替换且不进入缓存（事故经过见第~\ref{sec:robust}~节）。

\subsection{环境与关系账本}
环境模块（ElderSupportEnv）维护每位老人的关系账本：关系类型（子女/邻里/朋友/志愿者/社工）、强度 $s\in[0,1]$、每月联系频率与最近联系月份。当月无任何联系的关系按 $s \leftarrow s\times(1-\delta)$ 衰减（基准 $\delta=0.06$，敏感性扫描 0.15/0.25），$s<0.05$ 即删除。月度事件为患病、跌倒（均随年龄上升并降低健康值）与邻居或朋友搬走（对应关系删除）三类，基准月发生率分别为 0.10、0.03、0.02，属建模假设（附录~\ref{app:params}）。模拟对象均为独居老人，未建模配偶，因此不含丧偶事件。子女联系不作为事件，而由每条子女关系的月联系频率逐月生成。孤独感 $\ell\in[0,1]$ 每月以 0.5 的速度向稳态回归，稳态由当月情感接触数、关系数、健康与外向性决定（附录~\ref{app:params}），式中没有事件项，事件只经健康值间接进入。因此孤独感是孤立率的平滑函数，不是独立结局。$\ell\ge0.6$ 是手定切点，未用调查分布标定，正文不把它当作已对齐的靶标。

\subsection{三种干预}\label{sec:interventions}
\textbf{选择逻辑。}三者并非社会工作的三大实务方法（个案、小组、社区），也不处于同一层级：社工探访是专业服务，互助结对是以时间银行为载体的互惠机制，志愿匹配是经数字平台的志愿服务。本文比较的是它们共有的一个维度：为老人的支持网络补充哪一层关系、靠哪种关系逻辑维持。以护航模型\citep{kahn1980convoys}为框架，社工探访向网络注入正式支持节点并尝试修复内层的家庭关系，对应层级补偿模型中正式支持在非正式支持缺位时的补位\citep{cantor1979neighbors}；互助结对在中层建立同辈之间的互惠关系，依托互惠规范维持\citep{gouldner1960norm}；志愿匹配在外层按需撮合志愿者，提供的是弱关系\citep{granovetter1973weak}。三种关系逻辑分别对应``由谁补位''``能否自我维持''``能否按需触达''，因此适合用来比较干预撤出后关系能否持续。从政策领域看，三者分别对应社会工作（专业社工的外展服务）、社会保障（以互助积分为载体的互助养老）与社会管理（基层治理中的志愿服务平台），覆盖了社区为独居老人提供支持的三条主要渠道。现实中三者常组合实施，本文为识别机制而分开比较，不意味着它们互斥或可以相互替代。各干预对应的需求、代码中的服务行动、关系机制、观测指标、撤出条件与实现程度见表~\ref{tab:mechanism}。
\begin{itemize}
  \item \textbf{casework 风险导向的社工外展探访（社工探访）}：风险评估排序后对高危老人探访并联结家庭，自上而下、精准但受个案量约束。本文实现的只是个案管理中的风险筛查、定期探访与家庭联结三个环节，没有需求评估、服务计划、跟进与结案，因此不称为个案管理。效应方向参照 Masi 荟萃\citep{masi2011meta}与两个个案管理 RCT\citep{ristolainen2020effects,taube2018case}；覆盖率上限 $=$ 社工数 $\times$ caseload。
  \item \textbf{timebank 互助结对（时间银行）}：低龄健康老人结对高危老人、服务换积分，规则自动执行；结对是真实人际关系，撤出后以 post\_persist（中点 0.5；规则层扫描 0--1，含置零对照，表~\ref{tab:pp}）概率延续。机制设定参照香港时间银行准实验\citep{lu2024timebank}；撤出后延续概率无文献点估计，故作扫描处理。
  \item \textbf{platform 志愿匹配（数字平台）}：响应式、覆盖广、志愿者轮换、关系浅。效应设为三者最弱，方向参照技术类干预 CI 跨零的荟萃结果\citep{hoang2022interventions}。
\end{itemize}
\textbf{参数性质说明。}文献只为三种干预提供效应方向与相对强弱的参照；各干预的具体概率（如社工来访构成情感接触 0.8、联结家庭 0.5、互助结对当月成行 0.85、志愿匹配的志愿者关系强度上限 0.35）均为建模选择，未从文献效应量换算得到，取值见附录~\ref{app:params}。因此三种干预的效应大小之比不应被解读为对真实服务效果的估计。

\textbf{投入量不对等。}三种干预的服务量没有对齐：社工探访每月固定覆盖社工数 $\times$ caseload $=16$ 人（20 人中的 80\%）；互助结对受可用帮扶者人数限制；志愿匹配只对当月有生活事件或连续两个月无情感接触的老人、按 60\% 覆盖率派单。因此三种干预之间的结果差异同时包含``投入多少''与``机制本身''两部分，不能直接读作机制优劣。

\subsection{数据校准}\label{sec:data}
画像生成分布逐维锚定真实调查：年龄段、性别（女 63.8\%）、自评健康、孤独感基线五档、在世子女数、子女常探望比例（78.7\%）取自 CLHLS 2021 独居子样本（$n=1707$）；子女距离取自 CHARLS 2015。外向性、邻里朋友关系的数量与强度没有对应的调查锚点，为建模假设。另从 Harmonized CHARLS 2011--2018 提取了纵向靶标（独居老人三年孤独发生率 27.2\%、持续率 53.3\%），用于第~\ref{sec:calib}~节的动力学校准与留出检验。主批次画像经复核与按调查分布重新生成的画像逐字节一致（seed 1--3）。\textbf{已知偏差}：CLHLS 对高龄老人过抽样，本文年龄段直接按未加权分布抽样（80 岁以上占 69.4\%），画像因此偏老；用 CHARLS 加权年龄分布再加权列为后续工作。判定口径映射见附录与仓库文档。\textbf{校准覆盖范围的限制}：逐维锚定的只是全部 20 人画像的\emph{边际分布}，不是接触过程。规则层老人的月度接触按画像中子女的居住距离与是否常探望分档生成，但各档的月联系次数是建模假设，未经调查校准；焦点老人的接触过程由 LLM 行为决定（第 3.1 节），其基线孤立率（\FocIvNone\%）远高于规则层（\RulIvNone\%）。因此严格地说，与调查对齐的只是 20 人画像的边际分布；规则层的接触频率与 LLM 层的接触动力学都未经校准。输出侧有两项外部检验：关系存活曲线与 Burt 拟合不吻合（第~\ref{sec:honest}~节）；孤独动力学在规则层经校准后，留出的三年持续率误差为 4.6pp（第~\ref{sec:calib}~节）。后者是事后校准，主批次运行在校准前的默认动力学上，第 5 节的数字不受其影响。\textbf{规则层扫描的画像来源。}第~\ref{sec:mechanism}~节的时机与剂量扫描、harness 回路、衰减率与 post\_persist 扫描最初使用占位画像（各维度为固定的假设参数）。2026-10-21 已用校准画像重跑时机、衰减与 post\_persist 扫描，结论方向不变（\texttt{tests/*\_calibrated.json}）；正文表格仍报告最初版本，二者差异见第~\ref{sec:calib}~节。

\subsection{预注册与效度门槛}\label{sec:prereg}
假设（H1--H4）、主次结局、种子、有效性判据在正式批次启动前写入脚本头部：
\textbf{主结局} isolation\_rate（月度孤立率，定义为当月无任何情感支持接触的老人比例）；\textbf{次结局} avg\_loneliness；deep\_isolation\_rate 仅入敏感性分析，avg\_active\_ties 仅作描述。\textbf{效度门槛}：run 完成 24 月、决策记录非空、焦点老人静默率 $\le$10\%、LLM 调用错误率 $\le$5\%；任一不满足即判无效并整体重跑，无效 run 归档留存而非删除。$n=3$ 种子不做显著性检验、不宣称稳定排序；H4 为同 run 内``撤出期 $-$ 干预期''的配对对比，标注探索性。

\textbf{主结局的性质与局限。}isolation\_rate 是``本月有没有情感接触''的月度快照：任何按月上门的在场型服务（社工探访每月对覆盖对象以 0.8 概率触发一次情感接触）都会在定义层面直接将其清零，因此该指标在干预期内主要度量``服务是否在场''，图~\ref{fig:traj} 中第 7 月与第 19 月的阶跃即由此产生。孤独感 $\ell$ 是带稳态回归动力学的连续量（月末向由接触量、关系数、健康与性格决定的稳态回归一半），更接近真正的结局。预注册将其列为次结局，本文不改预注册地位，但在结果中将两者\textbf{并列报告}，并在解释效应量时以孤独感为准、以孤立率为``在场''指标。

\section{实验设计}
4 条件（none / casework / timebank / platform）$\times$ 3 种子 $\times$ 24 月，共 \TargetRuns\ 个有效 run 为目标，最终冻结 \ValidRuns\ 个：platform seed~2 因焦点老人静默率 11.3\%（17/150 agent-月）超过 10\% 门槛判无效。2026-10-20 复核该 run 的 trace：150 个 agent-step 全部完成，LLM 错误率为 0，17 个静默月分散在 5 名老人，不是网关超时造成的整月黑洞。2026-10-19 用同一配置补跑一次，静默率升至 60.7\%（91/150），LLM 错误率仍为 0；trace 显示老人先向环境询问能否联系他人，只读路由回答``不能联系''，老人随即结束本步。这是路由设计问题（第~\ref{sec:robust}~节），不是模型特性。补跑再次判无效，故不补进主结果，志愿匹配臂以 $n=\NPlatform$ 报告；干预期为第 7--18 月，撤出期为第 19--24 月。假设如下（预注册原文照录；其中``个案管理''即本文的社工探访条件，正式批次后按实际实现收窄了名称，见第~\ref{sec:interventions}~节）：
\textbf{H1} 干预期三种干预均降低孤立率，个案管理降幅最大；
\textbf{H2} 干预期孤独感同向改善；
\textbf{H3} 三种干预的行为签名可区分（求助路径、结对、志愿匹配）；
\textbf{H4}（探索性）撤出后个案管理反弹大于互助结对——结构性互助更可持续（预注册原文照录；第~\ref{sec:results}~节说明该形态由显式机制假设决定，不作为发现解读。``反弹''混入了干预期水平差，弱干预可反弹的空间本来就小，因此本文以撤出后水平及其相对从未干预组的残余作为可持续性比较量，反弹只在表中列出）。

\subsection{干预期效果（H1、H2）}
干预期社工探访孤立率 \IsoIvCasework\%，对基线 \IsoIvNone\% 相对下降 \CaseworkIvReduction；同 seed 配对差 \PairIvCasework pp（配对 $n=$\PairIvCaseworkN）。互助结对（\IsoIvTimebank\%）与志愿匹配（\IsoIvPlatform\%）改善有限。孤独感（并列报告）方向一致但幅度小得多：社工探访 \LonIvCasework\% 对基线 \LonIvNone\%（相对下降约 22\%，孤立率相对下降 \CaseworkIvReduction）——两指标的幅度差本身说明孤立率主要在测``服务在场''。这一排序与参数规定的在场效应同向：来访构成情感接触的概率为社工 0.8、互助结对受助方 0.6、志愿匹配 0.3，且志愿匹配需先满足事件或连续两月无接触才派单；孤独感经稳态公式随情感接触同步下降。因此 H1/H2 在本模型中由参数决定，不构成独立支持。

\subsection{撤出期可持续性（H4）}
撤出后社工探访孤立率反弹 \IsoRebCasework pp（同 seed 配对差 \PairRebCasework pp），干预期优势几乎清零；互助结对反弹 \IsoRebTimebank pp（图~\ref{fig:traj}、图~\ref{fig:paired}）。规则层 20 种子扫描给出同向形态（casework 反弹 \RulesRebCwLo\ 至 \RulesRebCwHi pp、timebank \RulesRebTb pp）。

\textbf{结果来源。}两条机制都写在环境规则里——社工探访的情感接触由社工每月来访直接触发，撤出即消失；互助结对撤出后以 post\_persist（中点 0.5）概率延续互动，代码注释明示``延续概率是 H4 的关键机制假设''。LLM 焦点老人与规则老人处在同一环境、共用同一指标定义，规则层与 LLM 层因此\emph{不是}两条独立证据，两层结果同向不构成跨层互证。H4 的准确表述是：\textbf{在显式编码的机制假设下，模拟复现了预期的可持续性分化，并给出了灵敏度范围}（caseload 4--12 不改变反弹；post\_persist 扫描见下）。它的价值在于把``退出后依赖型支持消失、互惠型关系部分存续''这一实务直觉变成可参数化、可反驳的模型，而非证明它为真。

\textbf{post\_persist 置零对照（规则层，\PPSeeds\ 种子）。}为直接检验分化是否由该参数制造，我们在规则层扫描 post\_persist $\in\{0,0.3,0.5,0.7,1.0\}$（表~\ref{tab:pp}）。结果分两半：（1）\textbf{撤出后水平}——post\_persist $=0$ 时互助结对撤出期孤立率 \PPPostTbZero\%，与社工探访（\PPPostCw\%）完全相同，即\emph{一旦结对不延续，互助结对没有任何可持续性优势}；随 post\_persist 升至 0.5/0.7，撤出期降至 \PPPostTbMid\%/\PPPostTbHi\%，优势完全由该参数供给。（2）\textbf{反弹幅度}——即便 post\_persist $=0$，互助结对反弹（\PPRebTbZero pp）仍小于社工探访（\PPRebCw pp，\PPLtCwZero/\PPSeeds\ 种子），但这只是算术：互助结对干预期效果更弱（\PPIvTb\% 对 \PPIvCw\%），可反弹的空间更小，两者撤出后回到同一水平。因此\textbf{以``反弹幅度''比较可持续性会系统性偏向弱干预}，正确的比较量是撤出后水平或相对基线的残余效应；本文主表（表~\ref{tab:main}）同时给出两者。另一附带观察：两种干预撤出后水平（\PPPostCw\%）均低于从未干预（\PPPostNone\%），说明规则层中干预期建立的关系强度有缓慢衰减的残余，这同样是 $\delta$ 的直接推论。

\subsection{分层拆解}\label{sec:layers}
表~\ref{tab:layers} 从 replay 中拆出 6 名焦点老人与 14 名规则老人各自的窗口均值。三点观察：（1）\textbf{焦点老人的基线孤立率约为规则老人的三倍}（none：\FocIvNone\% 对 \RulIvNone\%），源于第 3.1 节所述接触生成机制差异——焦点老人不行动即无接触；（2）\textbf{LLM 层主导了宏观效应}：焦点老人只占 30\% 人口，却贡献了基线孤立率的 \FocShareNone；社工探访对焦点层的配对效应（干预期 \PFocIvCw pp、反弹 \PFocRebCw pp）是规则层（\PRulIvCw pp、\PRulRebCw pp）的三至七倍。因此``生成式智能体模拟''并非装饰——但同时意味着主结果对 LLM 行为特征（含静默）高度敏感；（3）\textbf{互助结对的``不反弹''主要是规则层贡献}：规则层配对反弹 \PRulRebTb pp（post\_persist 起作用），LLM 层原始反弹 \PFocRebTb pp，与志愿匹配组（\PFocRebPf pp）相当，远小于社工探访（\PFocRebCw pp）。故 LLM 层支持的结论是``社工探访反弹远大于其余两种''，而非``互助结对几乎不反弹''。孤独感在两层均方向一致、幅度平缓。

\section{机制扫描：时机、剂量与提案--评估回路}\label{sec:mechanism}
\subsection{介入时机}
预注册规则层扫描（启动月 $\{3,5,7,9,12\}\times$ 时长 $\{6,12,18\}\times$ 3 条件，\TimingSeeds\ 种子；基线全时程孤立率 \RulesBaselineOverall\%）得到三点发现：
\begin{enumerate}
  \item \textbf{干预即时起效}：干预期内孤立率几乎不随启动时机变化——延迟的全部代价来自未被保护的等待月份，而非``错过关键窗口''；
  \item \textbf{延迟成本的方向性估计}：启动每推迟一月，两年平均孤立率上升约 \DelayCostCasework pp（casework）/ \DelayCostTimebank pp（timebank），24 月累计约 \DelayCumCasework\ pp（casework，基线 \RulesBaselineOverall\%）；platform 总效应弱故时机不敏感（\DelayCostPlatform pp）。该量级完全由``干预即时起效''这一规则属性决定（表~\ref{tab:prescribed}），只作规则层机制下的方向性估计；
  \item \textbf{反弹与剂量无关}：casework 时长从 6 月增至 12 月，撤出反弹不缓解（\RulesRebCwLo\ 至 \RulesRebCwHi pp；与置零扫描独立测得的 \PPRebCw pp 一致，两次扫描互相印证）——依赖型支持的反弹是机制属性而非剂量不足。
\end{enumerate}
注意披露：晚启动意味着更短的撤出期（混淆），时长 18 月无撤出窗；规则层绝对水平不与 LLM 批次比较，仅取方向与量级。预防期/预警期/危机期的 LLM 行为层时机对照未完成，属后续工作，此处不将计划写作结果。

\subsection{提案--评估回路（harness）}\label{sec:harness}
我们演示了受预注册约束的自动化科研回路：LLM 设计师在预注册搜索空间（条件 $\times$ 启动月 3--12 $\times$ 时长 6--12，目标最小化全时程孤立率，资源帽时长 $\le$12）内逐轮提出候选配置，确定性规则层评估器执行并返回结果，全部 \LoopIters\ 轮审计日志落盘。回路收敛到 \LoopBestDesc（全时程孤立率 \LoopBestScore\%），与资源上限内的网格最优（第 3 月起 12 个月，7.72\% $\pm$ 2.29）相差远小于种子标准差；2026-10-22 按原预注册重跑得到同一最优配置，改用校准画像重跑亦然（8.08\%，\texttt{tests/harness\_loop\_result\_calibrated.json}）——\textbf{回路流程成立，且我们如实报告它复现了网格平台区、并无超越网格的新发现}。护栏设计（LLM 仅提案、评估确定性、空间与轮数预注册、全轮次落盘）保证该演示不引入选择性报告。此外，逐 run 的自动分析--反思机制（analyze.py）目前实现``发现并标记''，修改实验配置前需人工审核，避免中途改变实验设计。需要说明，该回路只在固定的环境规则下搜索干预排期，不修改模型参数，也不把上一轮的结论自动带入下一轮；它证明的是回路可运行、选择性报告被挡住，而不是工具能够自行改进。第~\ref{sec:calib}~节把提案对象换成动力学参数、以留出靶标验收，是这一回路的下一阶段。

\subsection{画像消融与动力学校准}\label{sec:calib}
为回答``按调查生成的画像比普通随机好在哪''，我们在规则层做了预注册的画像消融（\texttt{tests/scan\_profile\_ablation.py}，脚本头部写定设计与判据后提交再运行）：三种画像来源各 20 个种子、每种子 20 人——\emph{校准}（CLHLS 边际分布逐维抽样，主批次所用）、\emph{普通随机}（锚定维度在同一取值范围内均匀抽取）、\emph{记录重抽}（从 CLHLS 独居受访者整条重抽，保留维度间相关）；未锚定维度三者相同。输入侧以五维总变差距离衡量贴合程度；输出侧在无干预条件下运行 48 个月（前 12 月预热），以截面孤独比例（15\%、40\%）、三年发生率（27.2\%）与持续率（53.3\%）四项靶标的平均绝对误差为主指标。

\subsection{关系衰减的结构性限制}\label{sec:decay}
以 Burt 口径实测本模型关系存活曲线（规则层 50 人 $\times$ 48 月）发现两点\textbf{机制层限制}：（1）模型关系流失显著慢于文献（4 年存活 \TieSurvFourYr\% 对 Burt 拟合 38.3\%）；（2）存在存活率地板：$\delta$ 从 0.06 扫至 \TieFloorDecay，4 年存活率触底于 \TieFloor\%（$\delta=\TieFloorDecay$ 时第 1 年即 \TieFloorYrOne\%，随后持平），仍高于 Burt 的 38.3\%——有固定联系频率的子女与高频邻里每月刷新联系时间，永不进入衰减分支，因此任何 $\delta$ 取值都无法复现 Burt 幂函数的持续下降（\texttt{tests/scan\_tie\_survival\_floor.py}）。我们据此\textbf{不将关系流失速率作为标定目标}，仅作敏感性维度。引用 Burt 时另有一处更正：其``家庭以外关系半衰期 2.63 年''为原文漏减常数项的算术错误，依原文方程重算应为 1.63 年\citep{burt2000decay}。深度孤立测度受存活率地板截断，故仅入敏感性分析。

\subsection{建模选择的扫描化处理}
三轮独立文献检索（第三轮经多源聚合接口覆盖 CrossRef/OpenAlex/arXiv）一致确认：不存在支持 $\delta=0.06$ 或 caseload $=8$ 的权威文献——凑出``完美吻合''数字的检索结果（本项目在第一轮检索中确曾遇到编造文献与编造数字各一例）已全部否决存档。因此这两个参数按\textbf{建模选择}处理：$\delta$ 扫描 0.06/0.15/0.25（扫描点依实测存活曲线选取）；caseload 在本模型中实际控制高危老人干预覆盖率（4/8/12 对应 40\%/80\%/100\%），与现实登记个案量单位不同——纽约市居家老人个案管理的实测平均登记个案量约 75 人/社工且被认为已超载\citep{pardasani2018caseload}，中国行业标准仅规定人力配置比而无个案量条款\citep{mzt064}，NASW 明确拒绝统一个案量标准\citep{nasw2013}，故按覆盖率维度扫描。扫描结论：$\delta$ 抬升整体水平但不改变干预排序；caseload 干预期内单调、撤出后收敛——覆盖率只影响在场效应，不影响可持续性。

\subsection{失效 run 的根因诊断}\label{sec:failure}
按效度门槛（第~\ref{sec:prereg}~节）判无效的 run 全部归档并逐一诊断，识别出两类失效模式：（1）\textbf{基础设施型}——LLM 网关错误风暴导致整月决策黑洞（错误在 trace 中成簇可见），处置为重跑并调高重试次数（基础设施参数，非协议变更）；（2）\textbf{接口型}——LLM 调用正常、错误率为 0，但老人在只读询问中得到``不能联系他人''的错误回答后不再行动。早先把它归为``行为型静默''并解读为模型特性，经 trace 复核（\texttt{ROUTER\_INCIDENT\_20261021.md}）确认是路由设计问题，见第~\ref{sec:robust}~节。处置为修复路由；修复前的 run 按原门槛判定，不补进主结果，不改门槛。

\subsection{模型与推理设定披露}
正式批次使用单一模型（gpt-5.6-sol）与统一采样设置；思考强度未被运行脚本记录，如实标注``未记录''，后续以小样本对照补充。跨模型稳健性（gpt-6-astra，seed~1，路由修复前后对照）列为敏感性检验，不在主结果内，结果见第~\ref{sec:robust}~节。

\subsection{跨模型对照与路由事故}\label{sec:robust}
以 gpt-6-astra 替换焦点老人的驱动模型，其余配置（画像、种子、干预参数、步数）与主批次 seed~1 一致。由于对照先后跨越一次路由修复，我们只做两组各变一个因素的比较：\textbf{路由对照}固定模型（Astra），比较修复前后；\textbf{模型对照}固定路由（旧路由），比较 Sol 与 Astra。新路由上的 Astra 不与旧路由上的 Sol 比较。两组都是单 seed、单 run 的描述性检验，不作统计推断。

\textbf{路由事故。}老人模型不能直接调用环境工具，只能用一句自然语言向环境提问。问句被标为只读时，代码生成路由只把只读工具交给另一个模型生成回答；写工具（打电话、串门、求助）虽已注册，但提示中没有要求区分``这一次不能写''与``世界上没有这个功能''，回答因此常说成``不能打电话、不能串门''。gpt-5.6-sol 多半不先询问、直接下令，静默率保持在 10\% 以内；gpt-6-astra 更常先询问，并把回答当作真实约束而停止行动。这与系统卡对该模型更守授权边界的描述一致\citep{openai2026astracard}。多模型对照在这里起到了单一模型做不到的作用：Sol 直接下令，掩盖了路由缺陷；Astra 先问再停，把它暴露了出来。2026-10-20 修复路由：询问功能是否存在时由注册表直接回答``工具存在，本次只读不能调用，要行动请用 readonly=false''，生成结果若仍称功能不存在则被替换且不进入缓存。事故时间线与旧路由上全部 8 场 Astra 的处理见附录~\ref{app:router}。

\textbf{修复后的结果。}新路由上 gpt-6-astra seed~1 四条件全部跑满 24 个月，焦点老人静默率分别为 \ArNewSilNone\%、\ArNewSilCw\%、\ArNewSilTb\%、\ArNewSilPf\%，LLM 调用错误率均为 0，全部通过效度门槛；旧路由上 none 为 \ArOldSilNone\%（无效）。静默基本消失，说明旧路由上的高静默来自环境回答，而非模型特征；此前``无人上门时更不行动''的解读继续撤回。casework$-$none 的配对差在修复前后同向：干预期压低（旧 \ArOldPIv{} pp，新 \ArNewPIv{} pp），撤出后回到接近不干预水平（反弹旧 \ArOldPReb{} pp，新 \ArNewPReb{} pp）。修复后幅度变小：旧路由下 none 的干预期孤立率更高（\ArOldIvNone{} 对 \ArNewIvNone），casework 更低（\ArOldIvCw{} 对 \ArNewIvCw）。互助结对与志愿匹配在新路由上干预期仅比 none 低约 3 pp，旧路由没有对应 run，不作前后比较。

\textbf{旧路由上的模型对照。}同一旧路由下，Sol 的静默率为 \McSolSilNone\%（none）与 \McSolSilCw\%（casework），均有效；Astra 为 \ArOldSilNone\%（无效）与 \ArOldSilCw\%。二者的差别主要不是任务行为的差别，而是对同一环境缺陷的敏感性：Sol 直接下令，绕开了错误回答；Astra 先问，就被它挡住。Astra 的 none 无效，旧路由上的 casework$-$none 配对差（Sol \McSolPIv{} pp，Astra \ArOldPIv{} pp）只作事故记录，不作为有效的模型差异。要得到干净的模型对照需在新路由上重跑 Sol，属新增付费实验，本文未做（第~\ref{sec:limits}~节）。

\textbf{对效度门槛的提示。}静默率门槛同时混合了故障、接口与模型差异；把``不行动''归因于模型之前，应先检查环境回复是否告诉了 agent 错误的能力边界。

\section{成本核算}\label{sec:cost}
多智能体 LLM 实验的成本报告必须计入被质量门槛淘汰的 run。本项目累计 LLM 调用 \TotalCalls\ 次（trace 实测，含归档失效 run），估算总成本 \$\CostTotal：主批次有效 run \$\CostValid、无效沉没 \$\CostWasted（占主批次 \WasteShare），另有跨模型对比臂 \$\CostModelCompare（第~\ref{sec:robust}~节）。token 用量为文档化假设（trace 未记录逐调用用量）、单价按公开定价，口径随数据文件公开。分层设计的意义在此具体化：规则层扫描（\TimingSeeds\ 种子 $\times$ 45 配置）与 harness 回路全部零 API 成本；若以 LLM 层完成同等扫描，成本将超出主批次一个数量级。

\section{核心结论与创新}\label{sec:core}
\textbf{核心结论。}（1）按调查分布生成画像是必要的，但不充分：只锚定画像时，输出端并不比普通随机更贴近现实，误差主要来自孤独动力学；动力学经预注册校准、以留出靶标验收后，调查锚定画像在输出端优于普通随机（第~\ref{sec:calib}~节）。（2）在本模型的参数下，三种干预的干预期排序为社工探访 $>$ 互助结对 $>$ 志愿匹配，这一方向对画像来源稳健，量级依赖输入；社工探访撤出后回到从未干预水平，互助结对撤出后的优势完全由结对延续参数决定（第~\ref{sec:results}~节）。（3）介入时机在规则层机制下表现为按月线性累积的延迟成本，而非``错过关键窗口''（第~\ref{sec:mechanism}~节）。

\textbf{方法层面的发现。}多模型对照暴露了单一模型发现不了的环境缺陷：Sol 直接下令，掩盖了路由把``这次不能写''说成``不能联系人''的问题；更守边界的 Astra 先问再停，把它暴露了出来（第~\ref{sec:robust}~节）。这提示 LLM 社会模拟中的``不行动''，须先排除环境告诉了 agent 什么，才能归因于模型或被模拟者。

\textbf{创新性。}（1）把``模拟是否只是规则回声''变成可检验的问题：结果来源对照表逐条标注，置零与扫描实验拆解关键结论；（2）把调查锚定从``画像像不像''推进到``输出准不准''：预注册消融加训练/留出校准，并如实报告校准前的负面结果；（3）分层架构让大样本扫描零 API 成本，同时保留 LLM 焦点层的行为与理由；（4）以社会工作、社会保障、社会管理三条渠道组织干预比较，使模拟问题直接对应实务决策。

\section{讨论：对实务的含义}\label{sec:discussion}
\textbf{（一）社工探访应内置退出计划。}干预期效果最强与撤出后回落是同一机制的两面：社工是被注入的活跃节点，撤出即失去接触，且回落不随服务时长缓解。退出设计——逐步减量、向互助结对等互惠网络转介——应作为外展服务的标准组件。

\textbf{（二）互助结对的可持续性取决于一个尚未测量的量。}模型中互助结对撤出后的优势完全来自结对延续参数，置零即消失。``社工探访开路、互助结对接续''因此只能作为待检验假设；它是否成立取决于真实结对关系在项目结束后的延续率，而现有时间银行文献尚未测量\citep{lu2024timebank}。测量它，比再做一次结局评估更能决定这类项目的政策价值。

\textbf{（三）轮候时间是可被设计的变量。}规则层机制下延迟成本按月累积（社工探访约 \DelayCostCasework pp/月）。这一量级依赖``干预一到位即产生接触''的假设，真实服务的启动滞后与覆盖爬坡会改变它。

\textbf{（四）先保证强度，再谈时机。}志愿匹配总效应弱，对时机不敏感；对弱干预优化时机意义不大。

以上均为模型推演，用于生成可检验的实务假设，\textbf{不宣称真实人群的因果效应}。

\section{结论}
本文提出并演示了一套面向社会工作干预研究的分层智能体模拟方法：LLM 焦点层嵌入规则层网络、画像锚定调查并经留出验证、关键机制参数外置，并配套预注册、效度门槛、失效根因分类、成本核算与结果来源对照。独居老人案例展示了沙盒的用法：社工探访、互助结对与志愿匹配的在场效应、撤出后的回落、结对延续对单一参数的依赖与介入时机的延迟成本，都可在显式参数下推演并接受置零或扫描检验。全部数字由脚本自动生成，欢迎按附录复现。

\section{局限与伦理}\label{sec:limits}
\textbf{局限。}（1）$n=3$ 种子（志愿匹配臂 $n=\NPlatform$），只支持描述性对比；（2）画像只对齐调查的边际分布；孤独动力学只在规则层做了事后校准（选中点在网格边界），接触频率与关系衰减仍为建模选择，关系存活曲线未通过 Burt 检验，LLM 主批次运行在校准前的动力学上；（3）三种干预的强度与投入量为建模选择、未与文献效应量或服务人次对齐，干预间排序由参数决定；（4）主结局孤立率是月度接触快照，孤独感由稳态公式决定，二者均非独立结局；（5）宏观结果主要来自 6 名焦点老人，对模型行为与静默敏感，撤出期仅 6 个月；（6）规则层时机扫描与 harness 回路只在固定规则下搜索，不修改模型参数；（7）主批次运行在修复前的路由上：主动询问环境的焦点老人可能得到``不能联系''的错误回答，Sol 有效 run 的静默率虽在 4.0--10.0\%，部分静默月与少行动月可能由此造成，焦点层结果应按此理解；新路由上未重跑 Sol，因此没有路由修复后的干净模型对照。后续工作见附录~\ref{app:params} 与仓库 \texttt{DATA\_MACHINE\_RUNBOOK.md}。

\textbf{伦理。}全部智能体为模拟实体，不涉及真实个人；调查数据仅使用公开微观数据的聚合分布；LLM 生成的``老人理由''是机制探针而非真实老人话语，论文避免将其拟人化引用。模拟结论若被直接当作资源分配依据存在误用风险，故本文反复强调其假设生成属性。
