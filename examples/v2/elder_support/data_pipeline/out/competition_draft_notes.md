## 一、框架（拟）

1. **问题与动机**
   - 独居老人社会隔离：政策干预（社工个案 / 时间银行 / 平台志愿服务）孰优、撤除后是否持续。
   - 传统调查数据难以观察"干预撤除后"的反事实轨迹 → 生成式 Agent 模拟的用武之地。
2. **方法：分层混合模拟**（本稿核心创新点）
   - LLM 焦点层（6 焦点老人，gpt-5.6-sol）+ 规则层（20 老人网络动力学），1 步 = 1 月。
   - 焦点层供机制与个体叙事证据；规则层供大样本敏感性扫描（零 API 成本）——大规模外推靠分层而非烧钱。
   - 校准：CHARLS/CLHLS 分布锚定（见 calibration_targets.md）；调用密度实测 13.8 次/焦点·月。
3. **实验设计**
   - 4 条件（none / casework / timebank / platform）× 3 seeds × 24 月；干预窗口第 7–18 月，之后撤除观察 6 个月。
   - 结局指标：isolation_rate、deep_isolation_rate、avg_loneliness、avg_active_ties。
4. **结果**（正式批次跑完后填充，规则层结论已可先写）
5. **稳健性**：decay（0.06/0.15/0.25）与 caseload（4/8/12）扫描。
6. **讨论与政策含义**
7. **局限与伦理**

## 二、已定结论（规则层扫描，2026-09-01，seeds 1–10）

- 干预期排序对 decay 稳健：casework < timebank < platform < none（隔离率）。
- **H4 机制**：撤除后 casework 反弹（isolation 0.030→0.146 @decay 0.15），timebank 几乎不反弹
  （0.069→0.080）——"结构性互助"比"外部投入"更可持续，是本稿最有政策价值的一句话。
- decay 抬升水平但不改排序；caseload 4/8/12 干预期单调、撤除后收敛。
- 详细数字见 `references_verified.md` 的规则层扫描章节。

## 二b、LLM 层初步结果（2026-09-03，7/12 run：4 条件 seed1 全 + seed2 除 platform）

⚠️ 初步口径：每条件仅 1–2 seeds，无显著性检验资格；seed 间方差不小
（none 的 deep_isolation 0.104 vs 0.371），**必须等 12 run 全齐再定稿数字**。

条件均值（干预期 7–18 月 / 撤除期 19–24 月）：

| 条件 | 干预期孤立率 | 干预期孤独感 | 撤除期孤立率 | 反弹 Δiso | n |
| --- | --- | --- | --- | --- | --- |
| none | 0.331 | 0.384 | 0.321 | −0.010 | 2 |
| casework | **0.081** | **0.288** | 0.271 | **+0.190** | 2 |
| timebank | 0.256 | 0.373 | 0.308 | +0.052 | 2 |
| platform | 0.221 | 0.347 | 0.258 | +0.037 | 1 |

初步结论：

1. **干预期 casework 遥遥领先**（孤立率 0.081 vs none 0.331，降 76%）——
   与 Masi 认知类效应最大的荟萃证据方向一致。
2. **H4 在 LLM 层复现**：撤除后 casework 孤立率反弹 +0.190（0.081→0.271，
   优势几乎清零，逼近 none）；timebank 仅 +0.052——"结构性互助更可持续"
   在两层模拟中都成立，这是跨层互证的核心卖点。
3. **LLM 层与规则层排序不完全一致**：干预期 LLM 层 platform(0.221) 略优于
   timebank(0.256)，规则层则 timebank 优于 platform。注意 platform 仅 1 seed，
   等 seed2/3 出来再判断是真差异还是噪声；若持续，写成"两层差异及其解释"
   而非掩盖（platform 在 LLM 层引入了新志愿者关系 → ties 6.42，机制上说得通）。
4. **机制佐证——求助成功率**：timebank 0.78–0.84 全场最高（结对互助起效），
   casework 请求量最大（128–150 次，社工主动触达）但成功率平平 0.65；
   none 仅 25–47 次请求。三种干预的行为签名清晰可辨。
5. **casework 的 ties 悖论**：撤除后 ties 仍高（6.4–6.5）但孤立率照样反弹——
   说明关系"存在"不等于"起作用"，撤除的是社工这个活跃节点的主动激活。
   这句可以写进讨论，很有社工实务含义。

## 2026-09-04 数据质量与机制限制补充

- 正式批次已发现 none_s2 有完整月份但零焦点决策，不能作为有效 seed；platform_s3 尚未完成。最终比较必须排除无效或未完成 run，并在补跑后冻结。
- 目前只有少量 seed，结果只作描述性比较。报告每个 seed、均值、标准差和范围，不把月度观测当独立重复，也不把 p 值当强证据。
- 关系衰减规则对无接触关系按月衰减，但频繁接触的子女和邻居会不断刷新，因此初始关系中约 46% 的亲属关系形成近似存活下限，不能复现 Burt 模型持续下降。
- 个案管理撤出后，已有关系仍可能保持较高，但孤立率仍反弹，说明“关系数量还在”不等于“支持网络仍能运转”。
- 平台与时间银行的排序可能在 LLM 焦点层和规则层不同，说明干预效果依赖行为机制层，不能只凭单一汇总排序下结论。
- 正式批次未记录思考强度；面板设置不等于批次配置。该事实须如实报告，低、中强度对照延后到主结果冻结后。
- 当前 trace 只有调用和耗时，货币与 token 只能作为估算，不能称为实际账单。
