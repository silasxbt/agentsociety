# 画像消融结果（2026-10-21，按 `scan_profile_ablation.py` 头部预注册执行，未改判据）

20 种子 × 20 人，规则层，decay 0.06，默认动力学与干预参数。

## A 输入保真（五维 TVD 均值，越小越贴近 CLHLS 边际分布）

| 来源 | TVD（均值±SD） |
|---|---|
| calibrated | 0.176 ± 0.034 |
| uniform | 0.249 ± 0.044 |
| resample | 0.162 ± 0.027 |

校准与重抽在输入侧明显优于普通随机。每种子只有 20 人，即便按真实分布抽样也有约 0.16 的抽样噪声。

## B 输出靶标（none，预热 12 月，至 48 月）

| 指标 | 靶标 | calibrated | uniform | resample |
|---|---|---|---|---|
| B1 截面 ℓ≥0.6 | 15% | 14.8% | 22.2% | 12.0% |
| B2 截面 ℓ≥0.45 | 40% | 24.5% | 38.8% | 20.2% |
| B3 三年发生率 | 27.2% | 9.7% | 16.1% | 9.7% |
| B4 三年持续率 | 53.3% | 98.3% | 97.8% | 100% |
| 主指标（四项误差均值） | — | 19.6pp | 16.0pp | 21.8pp |

**按预注册判据，校准画像在输出侧没有优于普通随机。** 误差主要来自动力学而非画像：
三种来源的持续率都在 98% 左右（靶标 53.3%），发生率都偏低。也就是说，模型里孤独状态
几乎不会自发进出，已经孤独的人一直孤独。普通随机的主指标更小，主要因为它的孤独初值更分散，
B2 碰巧接近靶标；它的 B1 偏高 7pp。校准画像只在 B1 上几乎命中。

## C 结论稳定性（24 月，同种子配对差，孤立率）

三种来源下干预期排序一致：社工探访 > 时间银行 > 数字平台（降幅）。幅度随来源变化，
普通随机下各干预效应约大 1.5 倍。即方向对画像来源稳健，量级不稳健。

## 含义

1. “比普通随机更好”目前只在输入侧成立；输出侧要先校准动力学。
2. 孤独动力学缺少状态转移：稳态由几乎不变的属性决定，导致持续率接近 100%。这是下一步校准的对象。
3. 干预排序对画像来源稳健，可作为论文中“方向稳健、量级依赖输入”的证据。

# 动力学校准与校准后复跑（2026-10-21，均按脚本头部预注册执行）

## 校准（`tools/calibrate_dynamics.py`，校准画像，种子 101–120）

新增 `lonely_noise_sd`（月度个体扰动，默认 0，回归 20/20 不变）。72 个候选全部评估：

| | 默认参数 | 选中参数 |
|---|---|---|
| relaxation / noise_sd / base | 0.5 / 0 / 0.90 | 0.2 / 0.20 / 0.90 |
| 训练误差（B1–B3 均值） | 12.7pp | 4.8pp |
| **留出误差（B4 持续率，未参与拟合）** | **43.1pp** | **4.6pp**（模拟 48.7%，靶标 53.3%） |

验收：V1 留出误差改善 ✔；V2 训练与留出误差 Spearman = 0.46 > 0 ✔。
注意：选中点落在网格边界（扰动上限、回归速度下限），按预注册不事后扩网格；扰动 0.20 较大，
可理解为未建模的生活事件，属于建模选择。

## 校准后复跑消融（种子 1–20，与拟合种子不重叠）

| | 校准 | 普通随机 | 真实记录重抽 |
|---|---|---|---|
| 输出主误差（校准前） | 19.6pp | 16.0pp | 21.8pp |
| 输出主误差（校准后） | **4.3pp** | 7.3pp | **4.2pp** |
| B1 截面 ℓ≥0.6（15%） | 21.2% | 29.8% | 19.5% |

校准动力学后，调查锚定的画像（校准、重抽）在输出侧优于普通随机约 3pp，普通随机主要在截面孤独比例上偏高。
**不对称**：动力学只在校准画像上拟合，这会偏向校准来源；但重抽来源未参与拟合，误差与校准相当，
说明优势不只来自拟合对象。干预排序在三种来源、校准前后均为社工探访 > 时间银行 > 数字平台。
